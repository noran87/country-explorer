# Country Explorer

A React app for searching countries, viewing their details, and managing a favorites list.

## Features

- Search countries by name
- View flags, capitals, regions, and area
- Add and remove favorites without duplicates
- Loading indicators and error messages

Favorites are stored in React state and reset when the page refreshes.

## Built with

- React
- Vite
- JavaScript
- Countries API: https://countries.dev

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## What I practiced

React state, event handlers, fetching API data, conditional rendering, components, props, and updating arrays.
